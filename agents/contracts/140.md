## 包字段清单

| 字段 | 含义 | 约束 |
|---|---|---|
| `query_spec_id` | 查询规格标识 | `^qspec-[0-9]{3}$` |
| `penalty_fact_package_ref` | 处罚事实包引用 | 不可变三元组 |
| `observable_fact_package_ref` | 可观察事实包引用 | 不可变三元组 |
| `query_goal` | 查询目标 | 非空 |
| `must_preserve_fact_refs` | 必须保留事实引用 | penalty_fact_id 列表，覆盖所有 yes/conditional |
| `main_object_and_grain` | 主对象和粒度 | 非空 |
| `query_entry` | 查询入口 | 入口表+条件 |
| `related_objects_and_path` | 关联对象与穿透路径 | 有序 |
| `filters_and_evidence` | 筛选条件及证据 | 每项含证据引用 |
| `return_fields` | 返回字段 | 非空数组 |
| `aggregation_dedup_sort_time` | 聚合去重排序时间 | GROUP BY 必填 |
| `observability_boundary` | 可观察性边界 | 可回答+不可回答 |
| `expected_result_shape` | 预期结果形态 | 行粒度+列集+聚合形态 |
| `sql_schema_scope` | SQL 表字段范围 | 每表字段在可观察事实中 |
| `minimum_positive_count` | 最少正例数量 | ≥1 |
| `minimum_negative_count` | 最少反例数量 | ≥1 |
| `condition_coverage` | 条件覆盖要求 | 每谓词正反例类型 |
| `code_value_coverage` | 码值覆盖要求 | 字段+目标码值列表 |
| `expected_row_group_count` | 结果行数/分组数 | low≤high, min≥0, target≥0 |
| `join_expansion_limit` | JOIN 发散上限 | multiplier>0, rows≥1 |
| `query_specification_package_schema_version` | 包协议版本 | `query-specification-v1` |

## 版本与血缘

- `version`：同一 `query_spec_id` 下从 1 递增；任何修改生成新版本，禁止覆盖。
- `supersedes_ref`：首次版本为空；迭代版本保存前一版本的不可变三元组。
- `attempt_no`：1、2、3；超过 3 进入人工审核。
- `parent_artifact_refs`：引用直接上游产物三元组。
- `input_hashes`：按输入顺序保存上游 content_hash。

## 审核回退路由

- 仅接受 170/180 审核包中 `error_types` 包含 `QUERY_SPEC_ERROR` 且 `route_suggestion=140` 的回退。
- 审核包的 `reviewed_package_ref` 必须精确等于被审核查询规格包三元组。
- 每次回退生成新版本，保留原始输入包引用不变。
