# Agent 120：监管处罚不可丢失事实构造

- 输入：010 冻结的 `penalty_source_package`（PENALTY-SOURCE-PACKAGE）。
- 输出：`penalty_fact_package`（PENALTY-FACT-PACKAGE），交 130/140/150/170/180 消费。
- 职责：
  1. 从结构化原始字段确定性提取不可丢失事实（主体、行为、时间、金额、处罚结果、监管结论）。
  2. LLM 补充跨 span 事实、外部法规证据、业务含义、处罚背景；证据必须带 URL、发布机构、日期与片段。
  3. 标注不确定性（缺失信息、歧义、span 不可验证、法规版本不清）；需人工审核的设 `needs_human_review: true`。
  4. 记录证据冲突（来源优先级 vs 外部证据）及解决状态。
  5. 支持 170/180 审核反馈驱动的重新提取（`re_extract_from_review`）。
- 非目标：不生成或修改 ORM；不写正式库；不直接消费 CoreBank 原始数据；不做 NL2SQL。
- 验收：schema 通过、事实 ID 连续不重复、span 引用全部存在于源包、quote hash 一致、枚举合法。
- 拒绝：源包 schema 版本不符、span ID 重复或缺失、fact ID 重复、证据片段为空、来源关联状态不一致。
- 权限：只读源包；产出为候选事实包，不直接提交正式库。
