# 约束资产发布总账

## 版本存放与发布规则（项目负责人 2026-08-12 裁定）

- `05_新版本交付层/` 仅保留各能力的**最新版**目录；历史版本降级归档至 `03_构建过程层/`。
- 发布到 `05_新版本交付层/` **无需项目负责人或 Codex 另行审批**，可直接提交与推送，简化操作。
- 后续若需再改，先把 `05_新版本交付层/` 中的旧内容降级到 `03_构建过程层/`，再把最新版放入 `05_新版本交付层/`。
- 当前按 `CA-V0.1.0 / CA-V0.2.0 / CA-V0.3.0` 分目录存放即可，但必须在 manifest 与总账中**写清楚**各自能力范围。

## 消费约定

不同版本为**能力分包**，不得仅凭版本号推断覆盖关系。消费端必须读取各版本 manifest 的 `capabilities` 与 `not_in_scope`，按能力域取用，不得把任一单包当作完整约束资产或 Foundation 数据源。
