# V5 治理合同

`governance-manifest.json` 是唯一机器入口，且以规范 JSON 计算 `content_sha256`。其稳定键与文件一一对应：`input_lock`、`root_contract`、`artifact_layout`、`workflow_policy`、`toolchain_contract`、`migration_map`、`downstream_contract`。

三根目录由环境变量提供绝对路径。`V5_REPO_ROOT` 是 Git 控制面；`V5_RUNTIME_ROOT` 保存运行期制品；`V5_REFERENCE_ROOT` 永远只读。三者不得相同、嵌套或相互别名。运行制品模板为 `${V5_RUNTIME_ROOT}/vnext/03_构建过程层/issues/{issue_id}/{run_id}/{attempt}`，attempt 只能是 1、2、3；同一身份内容冲突即拒绝。

状态依次使用 `backlog/todo/in_progress/in_review/blocked_manual/released/rolled_back`。仅列入策略的暂态失败可重试，第三次失败进入 `blocked_manual`。审核独立于实施；只有获批的 010 固定代码可以发布。配置更新必须先校验后原子替换，失败不留半成品。

旧目录和旧生成器只可作为参考；禁止直接复制。下游 EAS-15 只经 manifest 发现 `contracts/common/`、`src/east_v5/artifacts/`、`tests/artifacts/` 与运行期定位，先验证 schema/hash 后才可在运行根写入空开发占位物。

统一入口为 `python3 scripts/v5.py check`，依次执行 lint、type、schema、security、test。所有拒绝在副作用前返回稳定错误码；安全扫描阻断数据库、密钥、`.env`、日志和原始响应被追踪。
